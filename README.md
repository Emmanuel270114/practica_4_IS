Para poder correr la práctica 4 debemos de abrir una terminal como administrador en dirección de la carpeta donde se clono el repositorio y ponemos lo siguiente en la terminar:

npm run dev
De ahí nos arrojará una url que podremos poner en nuestro navegador para poder visualizar nuestra pagina de busqueda. La práctica esta ligada a una base de datos en donde podermos 
visualizar los usuarios creados y ya existentes, además de que va a contener tablas en donde podremos ver los favoritos de los usuarios y/o el historial búsquedas
